# Behavior Lock

The authoritative, line-cited record of every legacy Inkplainer behavior that
M00 freezes. All `file:line` references point to `legacy/index.html` (10,774
lines) or `legacy/animations.js` (3,575 lines). Values are verbatim from the
source. When implementation and this document disagree, the legacy source wins
during M00.

## Project

### IndexedDB schema
- **DB name**: `'WhiteboardAnimatorDB'` — `index.html:4250`.
- **DB version**: `1` (literal second arg to `indexedDB.open`) — `index.html:4250`.
- **Store**: `'projects'`, keyPath `'id'`, `autoIncrement: true` — `index.html:4262`.
- **Indexes**: `'name'`, `'createdAt'`, `'modifiedAt'` (all `unique:false`) — `index.html:4263-4265`.
- **No `schemaVersion` field**: confirmed absent (zero grep hits). The only "version" is the literal `1` passed to `open()`. There is no upgrade path — `onupgradeneeded` only creates the store if missing (`index.html:4261`). See KQ-003.

### Project record shape
Created by `createNewProject` (`index.html:4661-4666`):
```js
{ name, createdAt (ISO), modifiedAt (ISO), state: cleanState }
```
`id` is auto-generated by IndexedDB. `cleanState` defaults (`index.html:4643-4659`):
`canvasW:1280, canvasH:720, canvasBg:{type:'solid',val:'#ffffff'}, _currentRatio:'16:9', _currentRes:720, animStyle:'chunkjump', hand:'custom1', layers:[], selectedLayerId:null, groups:[], zigzag:true, outlineDetect:50, outlineAlgorithm:'classic', outlineStrokeStyle:'default', colorStyle:'filled'`.

### Create project
`createNewProject()` (`index.html:4639-4682`): `objectStore.add(project)` (`:4671`), then `loadProject(newId)` + `refreshProjectsList()` (`:4674-4676`). Name from `generateRandomName()`.

### Random name generator
`index.html:4238-4245`: `adjectives = ['Bright','Happy','Creative','Swift','Bold','Vivid','Fresh','Clever','Dynamic','Neat']`; `nouns = ['Sketch','Drawing','Board','Canvas','Design','Art','Doodle','Visual','Diagram','Scene']`; returns `` `${adj} ${noun}` ``. Uses `Math.random()` (`:4242-4243`).

### Rename project
Click `#project-name-editor` → `startRenaming()` (`index.html:4798-4807`); blur/Enter → `finishRenaming()` (`:4809-4840`): trims, if non-empty and changed updates `project.name` + `modifiedAt` via `objectStore.put` (`:4827-4829`). Escape cancels (`handleRenameKey`, `:4842-4850`).

### Autosave timing
**Debounce 5000 ms (5 seconds after last change).** `scheduleAutoSave()` (`index.html:4876-4881`): clears pending timer, sets `setTimeout(() => { saveProject(); }, 5000)`. `saveProject` (`:4272-4362`) serializes `state`, sets `modifiedAt`, `objectStore.put`, then `checkStorageUsage()` + `showSaveIndicator()`.

### Load project
`loadProject(projectId)` (`index.html:4376-4636`): reads record, restores canvas with defaults (`canvasW||1280`, `canvasH||720`, `canvasBg||{type:'solid',val:'#ffffff'}`), `_currentRatio||'16:9'`, `_currentRes||720` (`:4567-4568`), restores layers async (image dataURL → `Image.onload`), restores UI, then `clearUndoHistory()` (`:4629`).

### Delete project
`deleteProject(projectId, event)` (`index.html:4685-4706`): `event.stopPropagation()`; `confirm('Delete this project? This cannot be undone.')` guard; `objectStore.delete`; on `transaction.oncomplete`, if deleting current project → `createNewProject()`, then `refreshProjectsList()`.

### Startup
`index.html:5273-5295`: `initDB().then(...)` → `getAll()`; if no projects → `createNewProject()`; else sort by `modifiedAt` desc, `loadProject(projects[0].id)` (most-recent auto-loads).

## Image layer

### Upload
Drop zone `#drop-zone` (`index.html:3942`) click → `#file-input.click()`; input is `<input type="file" accept="image/*" multiple>` (`:3953`). Drop handler (`:8015-8018`): filters `f.type.startsWith('image/')`, calls `loadImageFile` per file. `loadImageFile` (`:8021-8029`): `FileReader.readAsDataURL`; `img.onload` → `addLayer(img, file.name.replace(/\.[^.]+$/,''))` (extension stripped for layer name).

### Auto scale
`addLayer` (`index.html:5793-5839`), `:5797`:
```js
const scale = Math.min(state.canvasW / img.width, state.canvasH / img.height) * 0.8;
```
Fits inside canvas preserving aspect, then **×0.8 (80%)**. So auto-scale = "fit-contain at 80%".

### Initial position
`index.html:5801-5803`: centered with stagger offset. `offset = (state.layers.length % 5) * 20`; `x = round((canvasW - w)/2) + offset`, `y = round((canvasH - h)/2) + offset`. First layer exactly centered; each subsequent shifts +20px (cycling every 5 layers).

### Transparency handling
`index.html:5806-5812`: probes a downscaled canvas (max 400×400: `sw2 = Math.min(img.width,400)`, `sh2 = Math.min(img.height,400)`); reads pixel alpha; if any alpha **< 250** → `hasPngAlpha = true`. Threshold: **`< 250`**.

### Layer object defaults
`index.html:5814-5828`: `resizePct:100`, `animStyle: state.animStyle || 'scanner'`, `hand: state.hand || 'custom1'`, `animOrder: null`, `opacity: 1`, `visible: true`, `groupId: null`, `speed: 40`, `handSpeed: 6`, `chunks: 30`, `specChunks: 35`, `baseW/baseH = w/h`.

### Resize
Slider (`index.html:6315`): `<input type="range" min="10" max="300" value="${resizePct}">`. **min=10, max=300** (%). `setLayerResize(id, pct)` (`:6416-6430`): `clamped = Math.max(10, Math.min(300, pct))`; resizes around center; `layer.w = Math.max(20, round(layer.baseW * clamped / 100))`. **resizePct default = 100** (`:5817`).

### Opacity
Slider (`index.html:6323`): `<input type="range" min="0" max="100" value="${opPct}">` where `opPct = Math.round(opacity*100)`. `setLayerOpacity(id, val)` (`:6391-6398`): `l.opacity = Math.max(0, Math.min(1, val))`. **Default 1, range 0–1** (slider 0–100%).

### Visibility toggle
`toggleLayerVisibility(id)` (`index.html:6453-6463`): `pushUndoSnapshot()`; `l.visible = !l.visible`; re-render. Eye icon in layer header (`:6298`).

### Rename
Two-click rename on already-selected layer (`index.html:6345-6366`): first click selects; second click within **400 ms** triggers `startLayerRename`. `startLayerRename` (`:6492-6518`): replaces name div with text input; Enter blurs (commit), Escape reverts; commit trims and sets `layer.name` if non-empty, then `scheduleAutoSave()`.

### Delete
`removeLayer(id)` (`index.html:5841-5866`): `pushUndoSnapshot()`; removes from groups, drops empty groups, filters out layer, reselects last layer (or null), clears outline overlays, re-renders, `scheduleAutoSave()`.

### Reorder
**Drag handle** (not buttons): `.layer-drag-handle` with `⠿` glyph (`index.html:6297`). `setupLayerDrag()` (`:6546-6557`) wires `onmousedown`. Drop in `onDragEnd` (`:6567-6585`): `itemH = 60`, `shift = round(dy/60)`, operates on reversed layer array, `pushUndoSnapshot()` only if `fromIdx !== toIdx` (`:6576-6580`), then `state.layers = revLayers.reverse()`.

## Layer animation ordering

### Numbered order
Each layer has `animOrder` (number or `null`). `getAnimOrder()` (`animations.js:2017-2022`): `ordered = visible.filter(l => l.animOrder !== null).sort((a,b) => a.animOrder - b.animOrder)`; `unordered = visible.filter(l => l.animOrder === null)`; returns `[...ordered, ...unordered]`.

### Blank order meaning
**Blank (`null`) layers are appended after all numbered layers and run in visual-stack order among themselves.** Layer default `animOrder: null` (`index.html:5820`), text default `null` (`:8338`), slicer default `null` (`:10240`).

### Same-order parallel behavior
`generate()` (`animations.js:2024-2050`): groups via `Map` keyed by `layer.animOrder ?? \`__${layer.id}\`` (`:2042`). Each distinct number → one group; null layers each get a unique key (`__${id}`) so they are **never parallel with each other** — each null layer runs in its own sequential group. `state._animGroups = [...groupMap.values()]`; `_runGroupAt(0)`. **Layers sharing the same numeric `animOrder` animate in parallel; layers with `null` each animate alone, sequentially, after all numbered groups.** Comment at `animations.js:1773`: "Layers with the same animOrder number animate simultaneously."

## Crop

### Activation
`activateCropTool()` (`index.html:9446-9480`): requires a selected layer, blocks if `state.playing`. Syncs crop-canvas size to main canvas, sets initial rect to layer bounds clamped to canvas, stores `_cropState = { layer, rect, dragging, dragHandle, startX, startY, origRect }`, adds `.active` to `#crop-canvas`, shows `#crop-action-bar`, disables `selectCanvas` pointer events. Toolbar button `#btn-crop-tool` (`:3797`) and layer-panel button `#btn-crop-layer` (`:4097`).

### Handles (8)
`_getCropHandle(px, py)` (`index.html:9618-9637`): 8 handles + move:
- Corners: `nw (x,y)`, `ne (x+w,y)`, `se (x+w,y+h)`, `sw (x,y+h)`
- Edges: `n (x+w/2,y)`, `e (x+w,y+h/2)`, `s (x+w/2,y+h)`, `w (x,y+h/2)`
- Hit radius `_CROP_HANDLE_HIT = 14` px (`:9617`). Inside rect → `'move'`.
- Visual: 4 corner L-brackets (`HS = 10`), rule-of-thirds grid, darkened outside (`rgba(0,0,0,0.48)`), white border `lineWidth 1.5` (`_drawCropOverlay`, `:9558-9614`).

### Move
Mousemove with `dragHandle === 'move'` (`index.html:9682-9684`): `x = max(0, min(canvasW - w, o.x + dx))`, same for y.

### Shift aspect lock
`index.html:9706-9709`: `if (e.shiftKey && _cropState.dragHandle !== 'move')` — uses `ar = layer.w / layer.h`; if `w/h > ar` then `w = h*ar` else `h = w/ar`. Locks to the **original layer's** aspect ratio.

### Reset / Confirm / Cancel
- `resetCropRect()` (`index.html:9491-9502`): resets rect to full layer bounds clamped to canvas.
- `cancelCrop()` (`:9482-9489`): nulls `_cropState`, hides crop canvas + action bar, re-enables `selectCanvas`.
- `confirmCrop()` (`:9504-9556`): `pushUndoSnapshot()`; stashes `layer._origImg/_origX/_origY/_origW/_origH` if not already saved; converts rect to image-space using `scaleX = naturalWidth/_origW`; draws cropped region into new canvas; on `newImg.onload` updates `layer.img/x/y/w/h/baseW/baseH/resizePct=100`, calls `cancelCrop()`, redraws, `scheduleAutoSave()`.

### Non-destructive source behavior
**Crop is non-destructive.** `confirmCrop` saves the original image into `layer._origImg` (with `_origX/Y/W/H`) before replacing `layer.img` (`index.html:9510-9516`); the slicer later reads `layer._origImg || layer.img` (`:10128`). Undo/redo serializes `origImageDataURL` from `layer._origImg` (`:4916`) and restores it (`:5053, 5082-5084`). See KQ-006.

## Slicer

### Modes
`openSlicerModal()` (`index.html:9738-9749`): requires selected layer; sets `_slicerLayer`, clears rects/paths, default `_slicerMode = 'grid'`, opens modal, `switchSlicerTab('grid')`. Three modes (`:9729`): `'grid' | 'rect' | 'freehand'`. Tabs at `:4144-4153`.

### Grid
Controls (`index.html:4170-4181`): `#slicer-cols` `<input type="range" min="1" max="8" value="2">`, `#slicer-rows` same. **Defaults cols=2, rows=2; range 1–8.** Grid generation in `applySlices` (`:10159-10173`): `cw = layer.w/cols`, `ch = layer.h/rows`; iterates `r` then `c`, each cell `bounds = { x: layer.x + c*cw, y: layer.y + r*ch, w: cw, h: ch }`, label `${layer.name} ${idx+1}`.

### Rectangle
`rect` mode (`index.html:10174-10179`): uses accumulated `_slicerRects` (`{x,y,w,h,label}`); each becomes a slice with `clipPts: null`, label `${layer.name} — ${r.label}`.

### Freehand
`freehand` mode (`index.html:10181-10187`): uses `_slicerFhPaths` (`{pts:[{x,y}], bounds:{x,y,w,h}, label}`); `clipPts = p.pts` (polygon in canvas-space). In `applySlices` (`:10208-10225`), if `clipPts.length > 2` builds a polygon clip path (coords converted from canvas-space to crop-canvas local via `scaleX/scaleY`) then `cctx.clip()` then `drawImage`.

### Layer inheritance
**Slices inherit the parent's animation settings.** `applySlices` builds an `inherited` object (`index.html:10137-10150`) from the source layer (falling back to `state.*`):
- `animStyle: layer.animStyle || state.animStyle`
- `hand: layer.hand || state.hand`
- `zigzag: layer.zigzag ?? state.zigzag`
- `textAnimDir`, `textDrawStyle`, `outlineDetect`, `outlineAlgorithm`, `outlineStrokeStyle`, `colorStyle`
- `opacity: layer.opacity ?? 1`
- `speed: layer.speed ?? 40`
- `handSpeed: layer.handSpeed ?? 6`

Each new slice spreads `...inherited` (`:10242`). New slices get `resizePct: 100`, `animOrder: null`, `visible: true`, `baseW/baseH = bounds`, `id: Date.now() + i*7`.

### Original removal
**The original layer is removed after slicing.** `index.html:10152, 10246-10249`: after all slice images load, `state.layers.splice(insertAt, 0, ...newLayers)` (inserts at original's index), then finds original's new index and `state.layers.splice(origNewIdx, 1)` removes it. `state.selectedLayerId = newLayers[0].id`. The original is replaced in-place by its slices.

Stacks are **in-memory only**, not persisted (`:4886` comment). Cleared on project load via `clearUndoHistory()` (`:5127-5131`, called at `:4629`).

### Snapshot structure
`_serializeState()` (`index.html:4895-4944`) — same shape as `saveProject`'s `savedState`: scalars (`canvasW, canvasH, canvasBg, _currentRatio, _currentRes, animStyle, hand, zigzag, outlineDetect, outlineAlgorithm, outlineStrokeStyle, colorStyle, selectedLayerId, groups`), `layers` array of `{ id, name, imageDataURL, origImageDataURL (if _origImg), origX/Y/W/H, x, y, w, h, baseW, baseH, resizePct, animStyle, hand, animOrder, opacity, visible, groupId, speed, handSpeed, chunks, specChunks, hasPngAlpha, outlineDetect, outlineAlgorithm, outlineStrokeStyle, colorStyle, outlineColor, outlineThickness, textAnimDir, textDrawStyle, zigzag }`. Note: `_serializeState` does **not** store `kind` or `_text*` metadata — only `saveProject` stores `kind`/`textProps` (`:4326-4327`). So undo/redo of a text layer loses the raw text metadata and treats it as a plain image layer.

### Push logic
`pushUndoSnapshot()` (`index.html:4947-4954`): if `_undoRestoring` returns; pushes a snapshot; if `length > UNDO_MAX_DEPTH (50)` shifts the oldest; clears `_redoStack`; `_syncUndoUI()`.

### Undo / redo
`undo()` (`:5110-5116`): pushes current state to `_redoStack`, pops `_undoStack`, `_applySnapshot(snap, 'Undoing…')`. `redo()` (`:5118-5124`): pushes current to `_undoStack`, pops `_redoStack`, `_applySnapshot(snap, 'Redoing…')`. Keyboard (`:5167+`, `:5203-5206`): `Ctrl+Z` → undo; `Ctrl+Shift+Z` or `y` → redo.

### Actions that CREATE snapshots (pushUndoSnapshot calls)
All `pushUndoSnapshot()` call sites in `index.html`:
`5314` bbSelectHand, `5794` addLayer, `5842` removeLayer, `6372` setLayerPos, `6385` setLayerOrder, `6392` setLayerOpacity, `6417` setLayerResize, `6453` toggleLayerVisibility, `6464` createGroupFromSelected, `6530` dissolveGroup, `6537` assignLayerToGroup, `6577` drag-reorder (only if `fromIdx !== toIdx`), `6794` canvas move/resize end (only `if (changed)`), `6826` selectHand, `6886` selectDetectAlg, `6921` selectOutlineStroke, `6949` selectColorStyle, `7077` applyPreset, `7768` selectAnim, `7835` selectBgPreset (only when `!_undoRestoring`), `7852` onBgColorInput, `7872` toggleZigzag, `7958` selectRatio, `7966` selectRes, `7975` setCanvasSize, `7984` slider mousedown (one snapshot per drag start) for speed-slider, hand-speed-slider, tile-slider, spec-tile-slider, outline-detect-slider, `8317`/`8321` _commitTextLayer, `9506` confirmCrop, `10124` applySlices.
In `animations.js`: `2945` selectTextDir, `2955` selectTextDrawStyle.

### Actions that do NOT create snapshots
- Text sidebar controls (`selectFont`, `toggleTextStyle`, `setTextAlign`, `selectTextColor`, `onTextCustomColor`, `updateTextState`) — only mutate `_ts` (live editor state); snapshot taken later in `_commitTextLayer`.
- `startLayerRename` / layer-name input commit (`:6501-6510`) — only `scheduleAutoSave()`.
- `renameGroup` (`:6487-6490`), `toggleGroupCollapse` (`:6481-6485`), `toggleGroupVisibility` (`:6520-6527`) — no snapshot.
- `resetCropRect`, `cancelCrop`, crop drag move — no snapshot (only `confirmCrop` snapshots).
- Slicer tab switching, slicer preview drawing, adding/removing slicer rects during modal — no snapshot (only `applySlices` snapshots).
- `scheduleAutoSave` itself — no snapshot.
- `loadProject`, `createNewProject`, `deleteProject` — no snapshot (they clear or rebuild state; `loadProject` calls `clearUndoHistory`).
- Continuous slider `input` events (speed/hand-speed/tile/spec-tile/outline-detect) — snapshot taken once on `mousedown` (`:7984`), not on each `input` tick.
- Canvas `mousemove` during drag (move/resize) — no per-move snapshot; only one snapshot at mouseup `if (changed)` (`:6794`).

### Stack size limit
`UNDO_MAX_DEPTH = 50` (`index.html:4889`). When exceeded, the oldest entry is `shift()`ed off (`:4951`).
